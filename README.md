## 👩‍💻 Sobre mim


💻 **Back-End & Web**
- Desenvolvimento de aplicações web utilizando **Java** e **Spring Boot**
- Criação e manutenção de **APIs REST**, implementação de operações CRUD e regras de negócio

📊 **Dados & BI**
